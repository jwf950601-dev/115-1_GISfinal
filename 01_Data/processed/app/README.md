# App 讀取的前處理成果

由 `preprocess/` 產生，後端 `backend/routing.py` 啟動時讀取。

| 檔案 | 內容 |
|---|---|
| `route_data.json` | 研究範圍內每個步行路口的座標、到最近車站的步行距離與「下一個路口」（步行樹）；自行車樹（從車站 350 m 內 YouBike 站出發）；軌道車站（100 m 內共站已合併）；YouBike 站點；繞路係數；示範地點 |
| `v3_data.json` | 機車路網（節點座標與路段秒數）、每個路口目前最快往返車站的時間、OSM 公車站牌 |
| `safety_data.json` | OSM 人行道／步道線段（11,643）、自行車道線段（1,792）；113 年 A1＋A2 事故（範圍內 14,958 案，一案一點；旗標 1＝行人、2＝自行車、4＝A1） |
| `metro_lines.json` | 臺北捷運 5 線與機場捷運：車站依 StationID 順序相連的線段（含新北投、小碧潭、蘆洲支線）與官方路線色 |

座標是 WGS84 經緯度；距離都在前處理時用 EPSG:3826（公尺）計算。
路網資料 © OpenStreetMap contributors（ODbL）。
